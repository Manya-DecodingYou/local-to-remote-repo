# this is the repo for the local to the remote site with the steps 
<p>
cd.. = to come out of the directory or the file<br>
mkdir = to make the directory
</p>

<p>
steps to local to the remote repo: <br>
1. git init to start the git in the local file<br>
2. add . = to add the all untraked files<br>
3. git commit -m"add the file" = to commit the all changes<br>
4. create new repo on the github without readme.md cause otherwise we have to take it on local computer<br>
5. add that repo to the local by using  = git remote add origin<-link-><br>
6. to verify the remote repo use = git remote -v <br>
7. git branch to check the branch<br>
8. git branch -M main = use to rename branch to main from master<br>
9. git push origin main / git push -u origin main (to set the seting to make all change to the main branch)<br>
</p>
